# LifeOS — Brand Guide

## Feel
Premium, calm, focused, professional, modern, minimal. Inspired by Linear, Notion, Apple, Raycast, and Arc — not copied from them.

Dark mode is the primary design; light mode and system-preference are supported but secondary.

## Typography
Inter, for both UI and body text. Weight 600–700 for headings, 400–500 for body. Avoid more than 3 font sizes on a single screen.

## UI principles

1. **Calm density.** Show what matters today; let everything else be one click away, not on-screen.
2. **Consistent components.** Every Academy, every resource type, every list uses the same Card/Badge/ProgressBar — no bespoke one-off layouts.
3. **Progress without gamification.** Progress bars and counts, not streak-shaming, badges, or confetti. Awareness, not addiction.
4. **Generous whitespace.** Padding over borders where possible; borders (`#334155`) only where separation is genuinely needed.
5. **Motion is subtle.** Fades and 150–200ms transitions only — nothing bouncy or attention-grabbing.
